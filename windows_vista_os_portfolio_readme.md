# 🪟 Windows Vista Aero OS Portfolio

An immersive, nostalgic, and highly interactive web portfolio mimicking the classic Windows Vista operating system. Built for **Siva Chandiran R** (Web Developer), this project transforms a standard resume into a fully functional web-based operating system featuring draggable windows, an Aero Glass UI, and live application simulators.

## ✨ Features

* **Authentic Aero Glass UI:** Highly detailed Windows Vista aesthetic including translucent title bars, realistic window shadows, pearl-style close/minimize buttons, and the iconic Start Orb.
* **Modular Window System:** Desktop icons (double-click/tap) launch independent, draggable, and resizable windows for different portfolio sections (Powered by GSAP).
* **Smooth Inertia Scrolling:** Buttery-smooth scrolling inside window viewports using the Lenis library.
* **Interactive Application Sandboxes:**
  * **Bespoke CRM (FastAPI/SQL):** A live simulated terminal to test GET/POST/PATCH endpoints.
  * **E-Voting DApp (Web3/Solidity):** A simulated Ethereum environment to cast cryptographic votes and generate transaction hashes.
* **Dynamic Wallpaper Personalization:** A built-in control panel to switch between classic Vista wallpapers (Aurora, Bliss) or upload/paste a custom image URL.
* **Taskbar & Start Menu:** Fully functional taskbar with window tabs, a working clock, and a Quick Launch start menu.
* **"Let's Talk" Direct Contact:** Built-in mailto integration for recruiters to instantly send inquiries.
* **Mobile Responsive:** The OS automatically adapts to mobile screens, resizing windows into touch-friendly modal views.

## 🛠️ Technology Stack

* **Structure:** HTML5
* **Styling:** Tailwind CSS (via CDN) + Custom CSS Variables for Aero Glass effects
* **Animations & Dragging:** [GSAP (GreenSock)](https://greensock.com/gsap/) & Draggable plugin
* **Scrolling Engine:** [Lenis](https://lenis.studiofreight.com/) by Studio Freight
* **Logic:** Vanilla JavaScript (ES6+)

## 🚀 Getting Started (Local Development)

Because this portfolio uses pure HTML, CSS, and Vanilla JavaScript with CDNs, there is no build step or package manager required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Diya-tec/vista-portfolio.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd vista-portfolio
   ```
3. **Run the project:**
   Simply double-click the `index.html` file to open it in any modern web browser, or use a tool like VS Code Live Server for hot reloading.
